Mode console développeur

Pierre, papier, ciseaux

La partie dure cinq manches. Ouvrez la console développeur (F12 ou Ctrl + Maj + J), puis tapez simplement un chiffre dans le champ ci-dessous à chaque manche. Le résultat et les scores apparaîtront dans la console.

  • 1 Pierre
  • 2 Ciseaux
  • 3 Feuille (papier)

Le tour démarre dès que vous tapez un chiffre valide.

La console affiche le choix de l’ordinateur, le résultat de chaque manche, le score, puis le nom du gagnant à la fin.

Pour jouer avec les boutons, retournez à la page .
